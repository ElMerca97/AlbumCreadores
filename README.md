# Álbum Maldonado de Creadores — V2

Esta versión reemplaza la primera demo por una interfaz mucho más cercana a un álbum móvil premium.

## Stickers incluidos
- `images/stickers/cundoo.png` — Cundoo #5
- `images/stickers/sangaraza.png` — Sangaraza #10

## Funciones
- Inicio con progreso del álbum
- Mi Álbum con casilleros bloqueados
- Mis Cromos con búsqueda
- Detalle ampliado de cada sticker
- Sobres clásicos y especiales
- Animación de revelado
- Retos
- Mi Equipo con cancha
- Monedas
- Guardado automático con localStorage
- Menú lateral
- Diseño responsive y pensado para celular

## Probar sin IDE
1. Extrae el ZIP.
2. Entra a la carpeta.
3. Haz doble clic en `index.html`.
4. Se abrirá en Chrome o Edge.
5. No hace falta instalar un IDE.

## Agregar más stickers
Coloca nuevas imágenes dentro de:
`images/stickers/`

Después habrá que agregar el jugador correspondiente en `js/app.js`, dentro de `defaultPlayers`.

## Convertir a APK
Cuando el diseño y las funciones estén terminados, este proyecto HTML/CSS/JS puede empaquetarse como aplicación Android. No es necesario rehacerlo desde cero.
